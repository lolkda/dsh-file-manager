# Agent Note: 将路径文本复制与文件复制分离

Status: implemented

## Problem

文件管理器已有的复制/剪切只维护文件任务剪贴板，无法直接把当前目录或勾选条目的 Host 绝对路径带到其他应用。用户确认需要两个独立入口，而且预览不应改变勾选集合。

旧面板的 openFile 同时设置预览和 selection，仅增加路径按钮无法满足选择语义。现在打开文件只切换预览，其他文件操作仍以同一勾选集合为准；需要操作预览文件时须显式勾选。

## Decision

- 面包屑旁提供“复制当前目录路径”图标（带标题和可访问名称），操作栏提供“复制所选路径”。没有根时不可复制；没有勾选时所选路径入口禁用。目录复制始终与勾选无关。
- 使用当前已展示的根绝对路径和根内路径拼接；不做额外 Host 请求，不校验存在性、不读取内容，只读模式仍可用。文件、目录和符号链接均复制自身路径，链接不解析目标。
- 多选按列表顺序以 LF 分隔，不加末尾换行、引号、@ 或 Shell 转义；目录不额外加斜杠，文件系统根保持 /。名称中的空格、引号和中文原样保留。
- 在用户点击调用栈内发起浏览器 writeText，不经网络或权限预查询。成功才显示“已复制”/计数；不可用、同步抛错或异步拒绝均显示失败与只读、可全选的完整路径文本。
- [路径复制模块](../../../../src/client/path-copy.tsx)拥有独立的瞬态反馈，不写入文件任务剪贴板，不影响会话、不执行文件操作。进行中不接受第二个写入；卸载后不回写状态，旧结果不能污染新实例。
- 沿用忙碌导航门禁和面包屑横向滚动布局。紧凑图标不引入长文本宽度，固定在滚动导航区域外。失败文本限制可见高度但保留完整值。

## Existing decision audit

为满足项目要求的 npm run verify-notes，复用 write-notes-like-deepseek skill 自带的目录、格式和归档验证器及公共模块，使用项目已有 Node 24 执行 TypeScript，不新增依赖或改动发布流程。

## Alternatives considered

- 单按钮按选中状态切换：控件最少，但选着文件时无法直接复制当前目录，用户选择两个明确入口。
- 复制相对路径、仅文件名或 Shell 引用：分别适合项目内引用和终端参数，但不是此次确认的跨应用原始绝对路径需求；不增加模式菜单。
- 复制前请求 stat 或借用会话引用接口：能获得新鲜存在性或现成引用格式，但引入等待、权限和引用语法限制，也妨碍复制已知但刚消失的路径，因此不使用。
- 保留预览自动勾选：能保持原有单击后操作的便利，但会改变用户明确勾选的复制目标，违反此次确认的选择语义，因此取消自动勾选，并让既有操作测试显式设置勾选前置条件。
- 使用旧式 execCommand 自动兜底：可能覆盖部分非安全上下文，但失败判定和焦点副作用更复杂；采用用户确认的可选文本兜底，不伪称复制成功。

## Testing

[路径复制测试](../../../../tests/path-copy.test.mjs)通过构建产物与真实 Host 路由覆盖根 /、嵌套路径、特殊可寻址名称、目录/链接、多选顺序、预览隔离、只读降级、失效路径、零新增请求、任务剪贴板与真实粘贴、三类剪贴板失败、关闭/重试和卸载隔离。独立 jsdom 用构建产物验证失败文本保真、不执行 HTML、只读状态与聚焦全选，不模拟系统剪贴板成功。

复现命令：npm run check；npm run verify-notes；npm test。权限测试须使用不能绕过 chmod 的普通用户。当前容器默认 root：初次全量运行中 4 项既有权限拒绝断言失败、6 项权限用例跳过；同组 46 项在 UID/GID 1000 下全部通过，未改动 Host 或权限测试来掩盖问题。

最终验证（2026-10-09）：npm run check 通过（类型检查、构建及 20 个产物语法检查）；npm run verify-notes 通过；setpriv --reuid=1000 --regid=1000 --clear-groups npm test 全量 764/764 通过，0 失败、0 跳过，其中新增路径复制回归 17 项，包含失败文本的真实 DOM 全选行为。git diff --check 通过。

## Consequences

用户可独立复制当前目录与勾选条目，路径文本不与文件任务状态混用，也不增加服务器流量。代价是打开预览后执行文件操作需要显式勾选，这是已确认的交互改变。路径只是界面快照，复制不承诺磁盘条目仍存在；需要命令行转义或相对路径时应另行决策，不在此隐式改变输出。

真实系统剪贴板权限和像素布局需要浏览器。当前 Chrome DevTools 无法连接 127.0.0.1:9222，未执行真实页面、系统剪贴板或深路径像素布局验收，安装与激活须单独核对，不在仓库中记录特定实例的部署结果。本地构建不等于 GUI 已加载变更。
