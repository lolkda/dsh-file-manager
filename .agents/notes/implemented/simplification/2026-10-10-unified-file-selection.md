# Agent Note: 统一直接勾选与稳定的列表状态栏

Status: implemented

## Problem

窄屏列表原本默认隐藏复选框，必须先点“选择”才能勾选，宽屏却直接可选。显式选择模式还让同一文件名的点击语义从打开变为勾选。首次选中后在列表上方插入数量提示，改变列表可视高度与条目位置。用户确认取消这一模式，并把数量合并到已有底部状态栏。

## Decision

操作栏的“上一级”入口由[精简文件导航](2026-10-10-compact-file-actions.md)删除；本篇其余直接勾选与稳定状态栏决定不变。

- 手机、Pad、桌面始终显示可操作条目的原生复选框。勾选只更新选择集合；文件名或图标始终打开文件或目录，遵循 R22 的预览/勾选隔离。链接可以勾选自身位置但不跟随；不可寻址及特殊条目不扩大权限。
- 不存在“选择／完成”按钮、模式状态、切换分支和窄屏隐藏规则。复选框图形保持 16px，标签触控区域至少 44×44 CSS px。
- 操作栏保持“上一级、新建、上传、更多”，不因选中动态替换。更多菜单末尾提供“清空选择”，无选择、无根或导航忙碌时禁用；清空仅更新本地选择，读权限降级不妨碍使用，保留批量操作的既有权限/保存门禁。
- 选中数量不独立占行。已有底部状态区域保持挂载、单行且高度不随选择变化；由“19 / 19 项”变为“19 / 19 项 · 已选 3 项”。数量取当前列表的有效勾选项，与批量动作一致；保留加载/条目计数及单一 polite 状态反馈。
- 列表状态栏通过专用类名与文档 footer 隔离，宽度不超过 600px 时高 24px，其余为 32px。宽屏辅助文案可省略，820px 及以下仅隐藏具名辅助文案，不以泛化 span:last-child 误伤计数。状态数字保留单行，极长文本可局部横向滚动，不使列表改变高度。
- 仅改变 Client 交互、样式、测试和说明，不改 Host、传输/存储格式、编辑器或任务语义，不新增全选、长按、范围选择或自动切换批量工具栏。目录导航、刷新对选择集合的既有行为不变。

## Existing decision audit

- [响应式覆盖式查看器](../feature/2026-10-09-responsive-file-viewer.md)：部分重叠，本篇替代显式选择模式和操作栏选择入口；覆盖层、焦点、导航和草稿生命周期不变，两篇互链，不归档。
- [路径文本复制](../feature/2026-10-09-copy-paths.md)：部分重叠且规则不变，继续以显式勾选集合操作、链接不解析、只读可复制；不替换其决定。
- [直接文件编辑](../feature/2026-10-10-direct-file-editor.md)：仅交互邻近，直接编辑与精简文件窗口契约不变。
- 实施前 proposed 无同主题笔记；rejected 目录不存在，没有可吸收或需否决的旧提案。本提案随实现转入 implemented。

## Alternatives considered

- 保留显式模式：点整行可方便连续多选，并给窄屏文件名更多空间；但用户要求三端统一，额外入口与双重点击语义比这些收益更显著，因此删除而非仅隐藏按钮。
- 为数量提示常驻空行或做位移动画：实现简单且容易让数量显眼；前者持续占用窄屏高度，后者只缓和跳动而没有消除布局变化，因此复用已有底部状态栏。
- 勾选后动态改为批量操作栏：常用批量动作更近；但会替换用户刚定位的按钮，并引入新的模式感，本次保持操作栏稳定。

## Consequences

三端操作含义一致，多选不再依赖模式入口；数量反馈利用已有状态栏，列表不因选中或清空发生位移。始终保留复选框列减少窄屏文件名可见宽度，使用现有单行省略与独立打开区域，不以扩大整行选择行为弥补。一键清空在更多菜单中，需要一次展开，但不会占用主工具栏或改变其按钮位置。

独立浏览器夹具没有认证当前 GUI，实际安装与重启生效须另行核对；本轮直接访问 GUI 返回 401，不查找登录凭据或启动替代服务器。物理手机触控、系统键盘与屏幕阅读器播报未由 headless/jsdom 验证，状态使用原生 checkbox 和 polite live region 保留语义。
