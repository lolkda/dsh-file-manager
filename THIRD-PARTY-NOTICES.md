# Third-party notices

The Client half of this package (`dist/client.js`) is a single bundled file. The
editor and its grammars are ordinary build-time dependencies, but bundling inlines
their code into that artifact, and a bundle never carries the dependency `LICENSE`
files itself. The published tarball ships only the built halves, so the verbatim
licence texts below travel with the package instead of being lost.

Everything listed here is **MIT-licensed third-party code inlined into
`dist/client.js`**. This package itself is `UNLICENSED` (see `package.json`); the
notices below grant nothing on its own behalf.

The durable contract of this file is the package names, their versions and the
verbatim licence texts; versions are the ones resolved by `package-lock.json` for the
release that ships this file. The bundle's byte size or hash is not part of that
contract.
